# knw_portfolio

천지현(Chun Jihyun) — 업무 자동화 포트폴리오 한 페이지.

게임 운영·CS의 반복 업무를 자동화한 RPA / 브라우저 확장 프로젝트를 영한 병기로 정리한 정적 페이지입니다.

## 구성

정적 페이지 두 장 (별도 빌드 없음). 공개 주소는 <https://intothinair0525.github.io/PF/> 입니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 메인(허브) — 두 작업물로 들어가는 진입점 |
| `rpa.html` | 업무 자동화 포트폴리오 (5개 프로젝트) |
| `assets/inter-tight.css` | 제목용 Inter Tight 폰트 4종 (base64 woff2 내장, 두 페이지 공용) |
| `case-studies/` | 프로젝트별 케이스 스터디 |

폰트까지 저장소 안에 들어 있어 외부 네트워크 의존성은 없습니다. 다만 두 HTML이 `assets/inter-tight.css`를
상대경로로 참조하므로, HTML 파일만 따로 떼어 열면 제목 폰트가 폴백으로 표시됩니다.

## 비고

원본 코드·데이터는 사내 자산이며 개인정보·내부 시스템 정보를 포함하여 비공개입니다.
이 페이지는 수행 내용을 민감 정보 없이 요약한 것입니다.
