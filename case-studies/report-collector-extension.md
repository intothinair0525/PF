# 운영툴 신고 내역 자동 취합 (Chrome 확장 + Apps Script)

운영툴의 신고 내역을 자동으로 수집해 Google Sheets에 적재하는 Chrome 확장 프로그램입니다.

## 배경 / 문제

- CS/운영 담당자가 운영툴에 쌓이는 신고 내역을 **수작업으로 복사해** 집계 시트에 옮겨 정리했습니다.
- 건수가 많고 반복적이라 시간이 오래 걸리고, 옮기는 과정에서 누락·오기입이 발생했습니다.

## 역할

Chrome 확장 + 서버사이드(Apps Script) 연동 구조를 **직접 설계·구현·배포**하고, 비개발 담당자용 설치·사용 가이드를 작성했습니다.

## 기술 스택

`JavaScript` · `Chrome Extension (MV3)` · `Vite`(빌드) · `Google Apps Script`(Web App 백엔드) · `Google Sheets`

## 핵심 구현 / 도전 과제

- **브라우저 확장 ↔ 시트 직접 연동** — 확장이 운영툴 화면에서 신고 내역을 수집하고, **Google Apps Script Web App**을 백엔드 엔드포인트로 두어 별도 서버 없이 시트에 적재하도록 구성했습니다.
- **Vite 빌드 파이프라인** — 소스를 번들링·배포본(zip)으로 빌드하는 파이프라인을 구성해, 배포 산출물을 일관되게 관리했습니다.
- **비개발자 배포** — `chrome://extensions`에 압축 해제 폴더를 로드하는 방식과 최초 설정 절차를 단계별 가이드로 제공해, 담당자가 스스로 설치·운영할 수 있게 했습니다.

## 성과

- 신고 내역을 수기로 복사·정리하던 작업을 **확장 버튼 조작만으로 시트 적재**되도록 전환했습니다.
- 서버리스(Apps Script) 구성으로 **별도 인프라 없이** 운영·유지보수 부담을 최소화했습니다.

*(민감 정보 제외: 운영툴 도메인·화면 구조, Apps Script 배포 URL, 대상 시트 정보는 원본에만 존재)*
