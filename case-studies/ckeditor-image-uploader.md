# CKEditor 이미지 다중 업로드 Chrome 확장

운영 어드민의 게시글 에디터(CKEditor 4 기반)에서 이미지를 여러 장 순차 업로드해 주는 Chrome 확장 프로그램입니다.

## 배경 / 문제

- 게임사 운영 어드민의 게시글 작성 페이지는 CKEditor 4 기반이라 이미지를 **한 번에 1장씩만** 첨부할 수 있었습니다.
- 공지·이벤트 게시글마다 이미지가 많아, 담당자가 "이미지 아이콘 클릭 → 업로드 탭 → 파일 선택 → 전송 → 확인"을 **수십 번 반복**해야 했습니다.

## 역할

문제 발굴부터 설계 스펙 작성, 구현, 배포용 빌드 스크립트, 설치 가이드까지 단독 수행. DOM 조작 흐름과 예외 처리를 정리한 **설계 문서를 먼저 작성**한 뒤 개발했습니다.

## 기술 스택

`JavaScript` · `Chrome Extension (MV3)` · `CKEditor 4 DOM/다이얼로그 제어` · `Node.js`(배포 zip 빌드 스크립트)

## 핵심 구현 / 도전 과제

- **에디터 업로드 흐름 자동 반복** — CKEditor의 이미지 업로드 다이얼로그 조작(아이콘 클릭 → 업로드 → 파일 선택 → 서버 전송 → 확인)을 프로그램적으로 재현해, 큐에 담긴 이미지를 순차 처리했습니다.
- **3가지 이미지 입력 방식** — 파일 선택 / 드래그 앤 드롭 / 클립보드 붙여넣기(Ctrl+V)를 지원해 실제 작업 흐름에 맞췄습니다.
- **안정적인 순차 처리** — 단계별 타임아웃을 적용하고, 개별 파일 실패 시 건너뛰고 다음 파일을 계속 처리하도록 해 한 장의 오류가 전체를 막지 않게 했습니다.
- **무손실 가로 크기 설정** — 재인코딩 없이 CKEditor 이미지 속성의 너비 값만 조정해 화질 손실·업스케일 없이 크기를 맞췄습니다.
- **선택적 업로드** — 큐의 이미지 중 체크박스로 고른 것만 업로드하도록 했습니다.
- **배포 자동화** — Node.js 빌드 스크립트로 배포용 zip을 생성하고, 시점별 배포 스냅샷 이력을 관리했습니다.

## 성과

- 수십 번의 수동 클릭 반복을 **한 번의 큐 실행으로 대체**해, 이미지가 많은 게시글 작성 시간을 크게 단축했습니다.
- 실패 건너뛰기·타임아웃 설계로 대량 업로드 중 **중단 없이 안정적으로 완료**되도록 했습니다.

*(민감 정보 제외: 실제 운영 어드민 도메인·계정, 내부 게시판 구조는 원본에만 존재하며 본 문서에서 추상화함)*
