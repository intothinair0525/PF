# 업무 자동화 프로젝트 케이스 스터디

게임 업계 재직 중 **사내 운영·CS 업무를 자동화**하기 위해 직접 기획·개발한 RPA / 브라우저 확장 프로젝트 모음입니다.

> ⚠️ 원본 코드·데이터는 사내 자산이며 개인정보(상담원 평가 데이터 등)·내부 시스템 식별자(Google 리소스 ID, 운영 어드민 도메인 등)를 포함하므로 **공개 대상에서 제외**했습니다.
> 이 문서는 "어떤 문제를, 어떤 방식으로, 어떤 역할로 해결했는지"를 보여주기 위한 **요약 케이스 스터디**이며, 민감 정보는 모두 추상화했습니다.

---

## 한눈에 보기

| 프로젝트 | 해결한 문제 | 형태 | 핵심 기술 |
|---|---|---|---|
| QA 평가 데이터 취합 | 상담품질(QA) 평가 데이터를 상담원별 개인 문서로 수작업 취합하던 반복 업무 | PySide6 데스크톱 RPA (Windows EXE) | Python, Google Drive/Sheets API, 레이어드 아키텍처, PyInstaller + Pyarmor |
| 커뮤니티 동향 취합 | 여러 게임 커뮤니티·게시판의 신규 글을 사람이 돌며 모으던 모니터링 업무 | PySide6 데스크톱 RPA (Windows EXE) | Python, Playwright, Google Sheets API, OAuth 2.0 |
| 신고 내역 취합 | 운영툴의 신고 내역을 수작업 복사해 시트에 정리하던 업무 | Chrome 확장 + Google Apps Script | JavaScript, Vite, Chrome Extension MV3, Apps Script Web App |
| 이미지 다중 업로드 | 운영 어드민 에디터가 이미지를 1장씩만 첨부 가능해 반복 클릭하던 업무 | Chrome 확장 | JavaScript, Chrome Extension MV3, CKEditor DOM 제어 |

관련 프로젝트: 별도 저장소로 분리한 **DaumEditor**(다음 카페 에디터 자동 스타일 확장)도 동일 맥락의 사내 업무 자동화 산출물입니다.

---

## 공통 특징

- **문제 정의부터 배포·사용 가이드까지 단독 수행** — 현업의 반복 수작업을 관찰해 자동화 지점을 도출하고, 직접 개발·배포·문서화했습니다.
- **비개발 실무자가 쓰는 도구** — 데스크톱 GUI(PySide6) 또는 Chrome 확장 형태로, 설치·설정 가이드를 함께 제공해 개발 지식 없이도 사용 가능하도록 만들었습니다.
- **외부 설정 기반 운영** — 수집 대상·매핑 등을 코드가 아닌 Google Sheets에서 관리하도록 설계해, 코드 수정 없이 운영 변경에 대응할 수 있게 했습니다.
