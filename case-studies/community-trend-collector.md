# 게임 커뮤니티 동향 자동 취합 RPA

PySide6 기반 Windows 데스크톱 RPA. 여러 게임 커뮤니티·게시판의 신규 게시글을 자동 수집해 Google Sheets에 적재합니다.

## 배경 / 문제

- 담당자가 매일 여러 게임 홈페이지·커뮤니티 게시판을 직접 돌며 신규 글을 확인하고, 동향 취합 시트에 수기로 옮겨 적었습니다.
- 사이트마다 구조가 다르고 일부는 JavaScript로 렌더링돼, 단순 복사로는 누락이 잦고 시간이 많이 들었습니다.

## 역할

기획·구현·배포·문서화 단독 수행. 수집 대상이 늘어도 **코드 수정 없이** 운영자가 관리할 수 있는 구조를 설계했습니다.

## 기술 스택

`Python` · `Playwright`(헤드리스 브라우저 스크래핑) · `PySide6`(GUI) · `Google Sheets API` · `OAuth 2.0`

## 핵심 구현 / 도전 과제

- **JS 렌더링 페이지 대응** — Playwright 헤드리스 브라우저로 동적 렌더링까지 처리해, 정적 요청으로는 못 긁는 게시판까지 안정적으로 수집했습니다.
- **중복 방지** — 이미 적재된 게시글 URL을 기준으로 신규 글만 선별 적재해, 재실행해도 중복이 쌓이지 않도록 했습니다.
- **외부 설정 기반 운영** — 수집 대상 게시판 목록을 코드가 아닌 **Google Sheets의 설정 탭**에서 관리하도록 설계해, 운영자가 대상 추가/삭제를 직접 할 수 있게 했습니다.
- **인증·토큰 자동 갱신** — OAuth 2.0 개인 계정 로그인 후 토큰을 자동 갱신해, 매 실행마다 재인증하지 않도록 했습니다.
- **실시간 진행 표시** — PySide6 GUI에 로그를 실시간 출력해, 수집 진행 상황과 오류를 즉시 확인할 수 있게 했습니다.

## 성과

- 매일 수동으로 여러 사이트를 순회하던 모니터링 업무를 **원클릭 수집으로 전환**했습니다.
- 대상 게시판 관리가 시트로 분리돼, 운영 변경 시 **개발자 개입 없이** 대응 가능해졌습니다.

*(민감 정보 제외: 수집 대상 사이트 목록, Google 리소스 ID, client_secrets/token 등 인증 정보는 원본에만 존재)*
