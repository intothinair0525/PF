# 잉크장부

타투이스트를 위한 수입·경비 기록과 종합소득세 미리보기 사이트.

## 만든 이유

타투 학원을 다니며 타투이스트를 준비하는 동안, 주변 동료들이 3.3% 원천징수와 현금·계좌이체 작업비, 잉크·니들·멸균 소모품 같은 경비를 어떻게 정리해야 할지 몰라 헤매는 걸 봤습니다. 2027년 10월 29일 문신사법 시행으로 사업자 등록이 가능해지는 전환기를 앞두고, 지금부터 기록 습관을 들일 수 있는 도구를 만들었습니다.

## 기능

- **장부**: 수입(직접 받음 / 3.3% 원천징수)과 타투 전용 경비 항목 기록, 증빙 여부 표시, 엑셀용 복사
- **세금 미리보기**: 단순경비율 신고와 장부 신고를 나란히 계산해 유리한 방법과 예상 환급·납부액 표시
- **절세 방법**: 노란우산공제, 연금저축·IRP 등 입력값 기준 예상 절세액 계산
- **홈택스 가이드**: 세금 일정, 5월 종합소득세 신고 순서, 문신사법 시행 후 준비 사항
- **FORMOSA TATTOO EXPO**: 대만 FORMOSA TATTOO EXPO에 타투 수강생 겸 어시스턴트로 참여한 기록

## 사용 방법

`index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 됩니다. 기록은 사용하는 브라우저에만 저장됩니다.

## 계산 기준

- 종합소득세 세율 6~45% (누진공제), 지방소득세 10%
- 단순경비율: 업종코드 940909 일반율 64.1%, 4,000만 원 초과분 49.7% (2025년 귀속 기준)
- 노란우산 소득공제 한도 600만 / 400만 / 200만 원, 연금계좌 세액공제 12~15%

모든 결과는 예상치이며, 실제 신고는 홈택스 안내나 세무사 확인이 필요합니다.
